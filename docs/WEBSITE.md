# Project website

The public address is https://danielep71.github.io/K-FRTB-ASA/.

The buildless website uses root `index.html`, `assets/site.css`, and the
existing `docs/assets/FRTB_social_preview.png`. It requires no JavaScript,
third-party fonts, package installation or calculation service.

## Publication

GitHub Pages deploys the site from the `main` branch, `/ (root)` folder, so a
change goes live only after it is integrated into main. The root `.nojekyll` file disables
Jekyll processing. Verify the Pages deployment and the live URL separately.

## Maintenance

Keep scope and validation wording aligned with README.md, docs/SCOPE.md and
docs/validation.md. Update through the active integration branch and normal
review procedure. Check navigation, local assets, keyboard focus, and desktop
and mobile rendering before publication. The website does not run the engine.
